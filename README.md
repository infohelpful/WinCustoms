# WinCustoms

**Windows 11을, 쓰기 편한 PC로 다시 맞추는 도구입니다.**

순정 Windows 11은 설치만 해도 광고·추천·기본 앱·새 UI가 잔뜩 붙습니다.  
WinCustoms는 그 불편함을 **한곳에서 끄고, 정리하고, 필요할 때만 되돌릴 수 있게** 만든 Windows 11 전용 유틸리티입니다.

.NET 런타임을 따로 깔 필요 없이, 배포본의 `WinCustoms.exe`만으로 바로 실행할 수 있습니다.

---

## 왜 만들었나

Windows 11을 새로 설치하면 보통 이런 경험이 따라옵니다.

- 우클릭 메뉴가 짧아져, 자주 쓰던 항목을 **‘더 많은 옵션’** 뒤에 숨김
- 작업 표시줄·시작 메뉴에 **검색·위젯·추천·광고성 콘텐츠**가 기본으로 켜짐
- Xbox, 뉴스, Teams, Solitaire 같은 **거의 안 쓰는 기본 앱**이 미리 설치됨
- 텔레메트리·팁·Spotlight 등으로 **개인정보·산만함**이 커짐
- 새 PC마다 같은 설정을 다시 맞추려면 **레지스트리·스크립트·Rufus·ADK를 제각각** 건드려야 함

WinCustoms는 “트윅 모음집”을 넘어서,

1. **지금 쓰는 PC**를 바로 다듬고  
2. **다음에 깔 Windows**까지 같은 취향으로 미리 만들 수 있게  

한 앱에 묶었습니다.

## 이런 분께 잘 맞습니다

| 이런 분이라면 | WinCustoms로 할 수 있는 일 |
| --- | --- |
| 방금 Win11을 깐 PC를 빠르게 정리하고 싶다 | 우클릭·작업 표시줄·광고·기본 앱·추천 프로그램을 순서대로 정리 |
| 회사·집안 여러 PC에 같은 환경을 반복하고 싶다 | 커스텀 ISO 또는 부팅 USB에 트윅·앱 제거·OOBE를 미리 넣기 |
| 잘못 건드릴까 봐 걱정된다 | 적용 전 `.reg` 백업, 복원 지점, 토글은 ‘적용’ 전까지 예약 |
| Rufus·DISM·레지스트리를 각각 만지기 싫다 | 부팅 USB·시스템 WIM 백업·트윅을 GUI로 처리 |
| 순정을 완전히 버리고 싶진 않다 | 항목마다 끄고 되돌릴 수 있음 (기본 앱 제거만 Store 재설치 필요) |

**맞지 않을 수 있는 경우:** Windows 10 전용 PC, 정책을 마음대로 바꿀 수 없는 회사 관리 PC, “손대지 않은 순정만” 써야 하는 환경.

## 순정 Windows 11의 답답함 → WinCustoms 기능

### 1. 탐색기와 우클릭이 답답할 때

순정은 새 컨텍스트 메뉴·홈·갤러리 중심으로 바뀌어, 예전에 익숙하던 흐름이 끊깁니다.

- Windows 10 스타일 **클래식 우클릭 메뉴**
- 탐색기 **홈 / 갤러리 숨김**, **‘내 PC’로 열기**
- 확장명·숨김 파일 표시, Compact 보기
- **우클릭 프로그램 등록·제거** — 메뉴에 올라온 항목을 지우고 복원하거나, 원하는 `.exe`를 파일/폴더 메뉴에 추가

### 2. 작업 표시줄·시작 메뉴가 산만할 때

가운데 정렬, 위젯·검색·추천, Bing 웹 패널이 기본입니다.

- 작업 표시줄 **왼쪽 정렬**, 단추 **결합 안 함**
- 위젯·검색·작업 보기·채팅·Copilot 아이콘 정리
- 시작 검색 **인터넷 결과·웹 패널 끄기**, 검색용 **브라우저 선택**
- 시작 메뉴 **추천·점프 목록·팁** 줄이기

### 3. 광고·추적·AI가 거슬릴 때

진단 데이터, 광고 ID, Spotlight, Copilot/Recall, Edge 백그라운드 상주 등이 기본에 가깝게 켜져 있습니다.

- 텔레메트리·광고 ID·팁·Spotlight·활동 기록·위치·클립보드 동기화 등 차단
- Copilot·백그라운드 AI, Edge 상주 차단
- 토글만 켜 두고 **한 번에 적용** (실수 여유 + UAC 최소화)

### 4. 기본 앱이 너무 많을 때

게임·뉴스·Teams 등이 미리 깔려 저장 공간과 시작 메뉴를 차지합니다.

- Xbox, Solitaire, 뉴스, Teams, Copilot, Clipchamp 등 **선택 제거**
- 권장 항목 일괄 선택 지원
- 복구는 Microsoft Store에서 해당 앱 재설치

### 5. 새 PC마다 필수 프로그램을 다시 찾을 때

설치 직후 런타임·압축·브라우저·에디터를 일일이 받기 번거롭습니다.

- **추천 목록** (ExplorerPatcher, Open-Shell, VC++/.NET/WebView2, 7-Zip, PowerToys, Chrome, Git, VS Code 등)
- **winget 검색**으로 원하는 프로그램 추가 설치

### 6. 성능을 조금 더 조이고 싶을 때

시각 효과, Delivery Optimization, Game DVR, Prefetch 등이 백그라운드를 잡아먹습니다.

- Ultimate Performance 전원, 애니메이션 최소화
- 다운로드 최적화·Game DVR·Prefetch(SSD 환경 권장)·네트워크 스로틀링 등 조절
- 종료 대기 단축, 드라이버 자동 업데이트 방지 등

### 7. 시스템 자체를 안전하게 되돌리고 싶을 때

잘못 건드렸을 때 “어제 상태”로 돌아가기 어렵습니다.

- **C: WIM 백업** — WinRE에서 오프라인으로 캡처 (pagefile·Temp 등 자동 제외)
- **C: 자동 복원** — 명령 입력 없이 다시 시작 후 WinRE에서 적용
- 트윅 적용 전 **시스템 복원 지점**, 레지스트리 **`.reg` 자동 백업**

### 8. 처음부터 “내 취향 Windows”를 깔고 싶을 때

매번 설치 후 같은 작업을 반복하기 싫을 때입니다.

- **커스텀 Win11 ISO** — 순정 ISO에 트윅·앱 제거·OOBE(로컬 계정, MSA 계정 건너뛰기, 요구사항 우회, 드라이버 주입 등) 이식
- **부팅 USB** — Rufus처럼 USB에 설치 미디어 작성  
  - 기본은 **순정 그대로**  
  - **최적화 설정**을 켜면 커스텀 ISO와 같은 트윅·디블로트·OOBE를 USB에 반영

## 안전하게 쓰도록 만든 방식

WinCustoms는 “빠르게 바꾸는 것”보다 **되돌릴 수 있는가**를 먼저 봅니다.

1. **적용과 복원이 한 세트** — 레지스트리 트윅은 적용 값과 기본값을 함께 정의해, 복원 없는 트윅을 만들기 어렵게 했습니다.
2. **적용 직전 `.reg` 백업** — `%LOCALAPPDATA%\WinCustoms\Backups`에 저장되며, 앱 없이도 더블클릭으로 되돌릴 수 있습니다.
3. **토글은 예약, 실행은 ‘선택 항목 적용’** — 실수로 켠 항목을 적용 전에 끌 수 있고, UAC도 한 번에 처리합니다.
4. **평소는 일반 권한** — 꼭 필요할 때만 짧은 승격 작업으로 HKLM 등을 처리합니다.
5. **위험도가 높은 항목**은 적용 전 한 번 더 확인합니다.

> 시스템 레지스트리를 바꾸므로, 중요한 작업 중이거나 백업이 없으면 사용하지 마세요.  
> 가능하면 상단 **복원 지점**을 먼저 만든 뒤 적용하는 것을 권합니다.

## 알아 두면 좋은 제약

- **Prefetch · Superfetch 끄기**는 SSD·메모리가 넉넉한 PC에 맞춘 옵션입니다. HDD나 저메모리에서는 느려질 수 있습니다.
- 시작 메뉴 **추천 영역 완전 제거**는 Pro/Enterprise 정책이 유리합니다. Home에서는 목록을 비우는 수준입니다.
- **기본 앱 제거**는 현재 사용자 기준이며, 복구는 Store 재설치입니다.
- **Windows 7 스타일 시작 메뉴**는 OS만으로는 불가해 Open-Shell 설치를 안내합니다.
- 부팅 USB·커스텀 ISO·시스템 복원은 **관리자 권한**과 잘못된 디스크 선택에 주의가 필요합니다.

## 기술 한 줄 (개발자용)

WinUI 3 (Windows App SDK) · .NET 9 · Native AOT 기반의 Windows 11 데스크톱 앱입니다.  
UI는 표준 권한으로 두고, 레지스트리·DISM·디스크 작업만 필요할 때 승격 프로세스로 짧게 실행합니다.

소스에서 직접 빌드·실행할 때는 .NET 9 SDK와 (Release AOT 게시 시) MSVC C++ 빌드 도구가 필요합니다.
